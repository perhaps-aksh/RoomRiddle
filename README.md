# RoomRiddle

**Gather. Investigate. Unravel the Mystery.**

RoomRiddle is a multiplayer mystery game built for TV-first cooperative play on **Amazon Fire TV / Vega OS**.

The TV is the stage and the game master. It presents the story, clues, puzzles, timer, decisions and endings. Players join by scanning a QR code with their phones, then investigate evidence, solve puzzles, submit answers, request hints and vote together. The whole room plays one synchronized mystery.

Every clue, hint, answer and ending is pre-authored and validated deterministically by an authoritative server. The game needs no AI to be fully playable.

## Platforms
- Amazon Fire TV on **Vega OS** (React Native for Vega), developed against the Vega Virtual Device
- Mobile web / PWA companion, with Android later

## Architecture
```
 TV (React Native for Vega) ─┐
                             ├─ WebSocket ─ Server (Node.js + TS, authoritative)
 Phones (web / PWA) ─────────┘                     │
                                          Game Engine (deterministic)
                                                   │
                                            Mystery Data
```

```
apps/
  tv/            Vega TV app (generated by Vega tooling, Milestone 0)
  player/        phone companion
  server/        authoritative game server
packages/
  shared-types/  types shared across TV, phone, server, engine, data
  game-engine/   pure rules and state transitions
  mystery-data/  pre-authored mysteries
  ui/            design tokens
docs/            architecture, game design, development, testing, friction log
```
See [docs/architecture.md](docs/architecture.md).

## Requirements
- Node.js ≥ 22 (developed on 24) and npm ≥ 10
- For the TV app: the Vega SDK on **Ubuntu 20.04+ or macOS 10.15+**. Windows isn't supported by the Vega SDK. See [docs/development.md](docs/development.md).

## Quick start
```bash
npm install
npm run check        # typecheck + tests
npm run dev:server   # http://127.0.0.1:4000/health
```

## Current development status
**Phase 1: Project Foundation.** Workspace, shared types, engine/data/server/player skeletons and docs are in place. Next up are Milestone 0 (hello-world Vega app in the Vega Virtual Device) and Milestone 1 (TV shell with D-pad navigation).

AI is intentionally deferred. The game engine is deterministic.
