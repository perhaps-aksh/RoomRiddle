# apps/tv: Fire TV / Vega OS app

The React Native for Vega TV app. It was **generated by the Vega CLI** (`vega project generate --template helloWorld`, SDK 0.24.12112) and must keep its Vega structure: `manifest.toml`, `package.json`, `metro.config.js` and the rest of the generated files.

- Package ID: `com.roomriddle.tv`
- Main component: `com.roomriddle.tv.main`
- Stack: React Native 0.83 + `@amazon-devices/react-native-kepler` ~4.0 on React 19.2

## Build and run (from Windows)
The Vega SDK and Vega Virtual Device run inside **WSL2 Ubuntu 24.04**. See `docs/development.md` for the one-time setup.

```bash
# build + (start VVD if needed) + install + launch
wsl.exe -d Ubuntu-24.04 -- bash /mnt/d/RoomRiddle/apps/tv/scripts/wsl-run.sh Debug

# build only
wsl.exe -d Ubuntu-24.04 -- bash /mnt/d/RoomRiddle/apps/tv/scripts/wsl-build.sh Debug
```

### Why the build runs in a mirror, not on D:
The source of truth is this folder on `D:`. `scripts/wsl-build.sh` rsyncs it (minus `node_modules` and `build`) to `~/rr-build/tv` on WSL's own ext4 filesystem and builds there. Building directly on `/mnt/d` caused two problems:
- `npm install` took about 15 minutes, against about 30 s on ext4.
- The packaged `.vpkg` came out with **zero-filled** `manifest.toml` and config files, so `vpt` failed with "failed to parse manifest". See FL-003 in `docs/friction-log.md`.

Edit files here on D:, then rerun the script. `node_modules` under this folder only exists for editor IntelliSense. The build never uses it.

## Workspaces
`apps/tv` stays outside the root npm workspaces. Vega pins its own React Native and React versions, and its dependencies must be installed from Linux. How it will consume `@roomriddle/shared-types`, `mystery-data` and `ui` (Metro `watchFolders` or a file dependency) is decided at Milestone 1 and recorded in `docs/architecture.md`.

## Milestone 1 scope
Home · Create Room · Join Room · Mystery Library · Settings. D-pad focus with an obvious focus state. Back must never destroy a room or progress without confirmation. No multiplayer, no AI.
