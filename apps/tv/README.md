# apps/tv: Fire TV / Vega OS app

This folder is **reserved** for the React Native for Vega TV app. Right now it's just this README.

The project here must be **generated by Amazon's Vega tooling** (Vega CLI / Vega Studio template) at Milestone 0, not written by hand as a generic React Native app. That keeps Vega-specific configuration intact.

## Why it's outside the npm workspaces for now
The root `package.json` lists `packages/*`, `apps/server` and `apps/player` explicitly and leaves `apps/tv` out, for two reasons:
- The Vega SDK runs on Linux (WSL2/Ubuntu) or macOS, never native Windows. The TV app's `node_modules` have to be installed from that Linux shell. The rest of the repo is installed from Windows.
- Vega pins its own React Native and React versions. Hoisting them into the shared root `node_modules` could clash with Metro.

Once the generated project builds and runs in the Vega Virtual Device, we'll decide how it consumes `@roomriddle/shared-types`, `@roomriddle/mystery-data` and `@roomriddle/ui`: npm/Yarn workspace, Metro `watchFolders`, or a file dependency. The decision goes in `docs/architecture.md`.

## Milestone 1 scope (after M0)
Home · Create Room · Join Room · Mystery Library · Settings. D-pad focus with an obvious focus state. Back must never destroy a room or progress without confirmation. No multiplayer, no AI.
